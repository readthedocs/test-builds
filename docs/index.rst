test-doc-diff
=============

GitHub page to test the DocDiff addon with content generated by JavaScript.
This page has copy buttons (sphinx-copybutton) and math rendered by MathJax.
Neither should show up as a change when the diff is enabled.

See https://github.com/readthedocs/addons/issues/528
